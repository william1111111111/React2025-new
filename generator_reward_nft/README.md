# Full reaction velocity reward post-training

This development experiment adapts NVlabs DiffusionNFT, arXiv:2509.16117, official revision `cbb14f84b8312b620390dfcbe2fab69c1383b104`. The reference script and its license are retained under vendor/. No image generator or image reward weights were downloaded. The original objective is not claimed as new.

Frozen original P2 supplies source encoding, cached BERT, semantic fusion and ref velocity. Full independent copies of all eight velocity blocks, conditional interactions and output layers form old/student. The standard recording noise is used directly. There is no 96D sampling policy and no log-probability surrogate. Sampling and reward computation are detached; a fresh noised endpoint is fed through the differentiable student. At each round end old is updated halfway toward student.

The formal objective is endpoint self-normalized positive/negative NFT (beta=1), plus 0.25 real TRAIN FM and 0.01 same-state ref vector-field MSE. The ref penalty is not exact KL. Masked means normalize each sample by valid frames and coordinates. Core velocity MSE is used only for analytic gradient checks. All 160 endpoints are used once per round, with independent new noising epsilon/tau. Eight endpoint microbatches and four independent real replay samples accumulate into one optimizer update. No top1 distillation.

N0-quality and N1-quality-coverage share 200 rounds, 16 TRAIN groups per round, K10, 4000 actual AdamW updates, seed123, lr2e-5, weight decay0.01, warmup100 and norm clip1. N1 alone adds v2 quality-gated column-wise marginal coverage. Its fixed geometry and bandwidth retain the known AU-dominance limitation. Fixed64 TRAIN calibration fits alpha and pooled centered reward scales before either formal run. r is a weight, not a probability. No eligible pair means r<=0.5; tied group rewards are neutral.

TRAIN real and parent per-group native speed/acceleration q95/q99/max are recorded. No scenario-validated dynamic anomaly classifier is available, so only domain-invalidity is penalized; empirical motion quantiles are diagnostics, not a claim of natural motion. The previous near-range-max motion gates are not reused as naturalness evidence.

The schedule cycles randomly over the full eligible TRAIN population; replay uses an independent schedule and reward-independent uniform target slot. Original paired times and same-session alternative interpolation are retained. Frozen source semantics are NULL when unavailable. There are no new LLM calls or external media uploads.

Checkpoints 0/500/1000/2000/4000 and atomic latest contain student, old, frozen ref identity, optimizer, dual/EMA, round, endpoint buffer/index and RNG. Each sampled group persists detached internal24 clean, native25 prediction, conditions, masks, source/crop/target identities and hashes, behavior/noise hashes, reward scores and weights. Per-group files permit sampling-stage resume without repeating complete groups. Completed reference banks are shared under per-record locks; action and independent reference rollout costs are recorded. Ref bank generation is not added to candidate outputs.

Full native source-only DEV80 evaluation is scheduled at1000/4000; final4000 uses exact FRD20 (2000 pairs/arm, resumable pair cache). FRC/S-MSE/FRVar and FRD final values refer to the same student checkpoint. No score-selected checkpoint columns. Reports include native motion, group DC/slow/fast and candidate quality tails. No automatic push, reward grid or extension beyond4000.

Commands: `.venv/bin/python -m generator_reward_nft.prepare`, `calibrate`, `check`, then `queue`. The queue freezes source/input hashes after successful calibration and real acceptance. GPU0 is explicitly inherited from the user's authorization. Jobs run detached with persistent logs, heartbeat and exit records. Existing M0/M1 and policy results remain untouched. Synthetic vendor checks do not substitute for ACCEPTANCE.json's real TRAIN evidence.
