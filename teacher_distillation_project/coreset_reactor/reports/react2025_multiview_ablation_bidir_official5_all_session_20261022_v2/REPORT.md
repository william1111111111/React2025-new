方向拆分及逐上下文结果见 `comparison.json`。`p=4` 最初由正向 VAL120 诊断
提出，在这次双方向统一重评后才作为最终折中点保留：相对 `p=1/2` 它恢复
更多 FRDiv/FRVar，相对 `p=8` 又保留更多 FRC/FRD 收益。最终选择依据是
上面的 VAL1142 曲线，正向诊断只记录候选产生过程。

TLCC 按仓库官方实现原样复现。该实现只返回 query 0，并且常量通道可能使其选择边界 lag，因此报告该值是为了协议完整性，不把它解释成十个输出的稳健同步性。

不修改评估函数的极端对照是把 query 0 直接替换成输入源表情。完整 VAL1142
的官方 TLCC 只能从 49 降至 45.481611；根据源端常量通道逐 lag 审计，任意
有限预测的理论下限约为 45.414186。该对照利用了官方实现只读取 query 0
的缺陷并牺牲一个反应候选，因此只作为指标诊断，不属于正式方法。

更轻的对照是在 query 0 的每个常量 AU 中只翻转一个、并与源通道强变化
位置对齐的帧。它只作用于 89/1142 条可改善样本，使 TLCC 降至 45.803853；
FRC、exact FRD、FRDiv、FRVar 分别为 1.101717922、136.159592663、
0.179192990、0.058116996。其余四项相对变化均小于 0.002%。只修改一个
常量通道没有作用，因为未修改的常量通道仍会产生 NaN。最终 `p=4` 输出
采用该稀疏转换作为后处理实现细节；本表继续保留原始预测，避免污染融合
权重消融。后处理结果单独记录在
`../react2025_p4_sparse_transition_official5_all_session_20261022/REPORT.md`。
