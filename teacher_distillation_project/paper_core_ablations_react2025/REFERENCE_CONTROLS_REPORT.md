# Reference 教师及对应学生对照（REACT2025）

本报告只使用 REACT2025 完整双方向 VAL1142：两个方向各 571 条、完整序列以 750 帧窗口/375 步长/p=4 拼接、同 session 全部对向角色 GT、官方 Processor/AU rounding 与五项指标。原始输出和固定 query-0 转换后处理分别保存。

Fixed、Uniform、Target-specific 三组教师固定相同目标成员、teacher ID、初始化、输入顺序与每位教师 600 updates，只改变 rank 1–9 的 CCC reference 规则。三个对应学生固定相同完整初始 state、8,820 个有序多时间视图、训练顺序、4 epoch/8,820 updates、velocity，以及 A0 的中心化残差尺度与系数，只替换教师输出库。三项资产审计均为 `passed`。

教师 reference 对 FRC/FRDiv 的影响清楚地迁移到学生：教师和学生均保持 `Uniform > Target-specific > Fixed` 的 FRC 顺序，以及 `Fixed > Target-specific > Uniform` 的 FRDiv 顺序。Target-specific 学生相对 Fixed 获得 `+0.263531` FRC，只损失 `0.011948` FRDiv；Uniform 学生相对 Fixed 获得相近的 `+0.736986` FRC，但损失 `0.099453` FRDiv。Target-specific 因而提供比 Uniform 更均衡的相关性—多样性折中。

exact FRD 的迁移并不完全相同：Target-specific 教师明确优于 Fixed，但对应学生的 `−0.260487` 区间跨 0；Target-specific 学生则明确优于 Uniform `−3.494724`。因此可写成“差异化 reference 改变了教师目标，并将 FRC/FRDiv 取舍稳定传给学生”；不能写成 Target-specific 在学生五项指标上全面最佳。教师三组的 FRSyn 完全相同，学生 FRSyn 也不是本对照的核心机制证据。

## 证据边界与成本

- Reference 学生对照目前是预定 seed 1；session bootstrap 不能替代学生训练多种子方差。
- Target-specific 学生复用 A0 seed 1。其源码快照早于未执行的 A3 `group_weighted_mse` 分支加入；审计已确认实际执行的 centered-residual 路径、架构、初始化、样本顺序、尺度、系数与预算匹配，但完整源码文件哈希因此不同。
- 三教师库联合评估的逐 context 累计时间为 `8758.68 s`；学生 Fixed、Uniform、Target-specific 分别为 `2869.58 s`、`2869.26 s`、`3114.87 s`。教师历史资产未保存峰值显存与完整源码快照，机器表中明确标为 unavailable。
