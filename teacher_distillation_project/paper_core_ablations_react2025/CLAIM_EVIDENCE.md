# Claim—Evidence: A0 vs A1

本页先列 seed 1 的机制与配对细节，再给出三个预定学生 seed 的稳定性结论。

## 差异迁移诊断

- **AU**：中心化残差 MSE 0.00951881 → 0.00945061；pair-distance MAE 0.0261634 → 0.0264325。
- **VA**：中心化残差 MSE 0.0109513 → 0.00744159；pair-distance MAE 0.0402552 → 0.033572。
- **EX**：中心化残差 MSE 0.00657729 → 0.0059084；pair-distance MAE 0.0248337 → 0.0230381。
- 教师 soft-FRDiv 保留率（均值之比）：A1 `0.913168`，A0 `0.916825`。

## 可支持的论文表述

在固定教师和训练预算下，显式中心化集合差异监督降低了 AU、VA、EX 三组的中心化残差 MSE。pair-distance 只在 VA、EX 改善，AU 略退，因此证据支持的是中心化差异表示的迁移，不是所有关系度量都一致改善。

VAL1142 上 exact-FRD 明确改善；FRC 和 FRDiv 的 session bootstrap 区间跨 0，FRVar 降低，后处理 FRSyn 增大。因此 seed 1 支持机制迁移和 FRD 收益，不支持整体五指标全面优于 A1。

## A0/A1 跨训练种子稳定性

seed 2、3 使用同一教师库和缓存，各自在 seed 内冻结匹配的完整初始 state、输入顺序、velocity、优化器和 8,820 updates。三个 seed 的 A0−A1 既定后处理 exact FRD 分别为 `−1.934087`、`−0.858153`、`−1.827889`；每个 seed 的 session-cluster 95% CI 均完全小于 0。跨 seed 均值与样本标准差为 `−1.540043 ± 0.592917`，即 3/3 个预定 seed 改善。

相反，FRC 点估计在 3/3 个 seed 都降低，跨 seed 为 `−0.003888 ± 0.003067`；FRDiv、FRVar 与 FRSyn 方向不稳定。可写为：中心化集合差异监督更准确地迁移教师集合的中心化残差结构，并在三个预定学生 seed 上稳定降低 exact FRD。不能写成 A0 全面优于 A1。完整绝对分数、每 seed 区间及原始输出见 `MULTISEED_REPORT.md` 与 `MULTISEED_A0_A1.json`。

## 教师目标是否比直接真实参考有价值

控制比较为 A1 对 A2：同一完整初始 state、8,820 个有序输入视图、目标身份分配、训练顺序、架构、更新数和推理流程，只将监督张量从教师 AFR 换为教师原本指定的真实 AFR。保留 velocity 与双方同时删除 velocity 的两套比较结论一致。

- 保留 velocity：A1−A2 后处理 FRC 为 `+0.332403`，session 95% CI `[+0.215055,+0.392885]`。
- 双方删除 velocity：A1−A2 后处理 FRC 为 `+0.330662`，session 95% CI `[+0.212037,+0.391331]`。
- 两套比较中 A1 的 FRDiv 分别低 `0.005707`、`0.006055`；exact FRD 点估计偏向 A1，但区间跨 0。

可写为：在固定目标身份与训练预算下，教师生成 AFR 相比直接监督指定真实参考显著提高了 FRC；该收益伴随 FRDiv 降低，不能写成所有质量与多样性指标全面改善。

## 中心化差异项是否优于同尺度未中心化 MSE

A0/A3 固定教师、缓存、完整初始 state、训练顺序、velocity、尺度、系数与 8,820 updates。A0−A3 后处理结果为：FRC `+0.012940`、FRDiv `+0.000819`、FRVar `+0.000986`，对应 session 区间均不跨 0；exact FRD 为 `+1.654058`，区间 `[+1.192346,+1.952515]`，即 A3 更好。

差异迁移诊断中，A0 的 AU/VA 中心化残差误差低于 A3，EX 基本持平，三组 pair-distance MAE 均更低。这支持中心化目标更直接地迁移教师集合内部关系，但真实 GT 指标存在明确取舍，不能写成 A0 全面优于 A3。

另一个限制是 A0/A3 初始加权辅助梯度/基础梯度比分别为 `0.2518` 与 `2.2065`。虽然尺度和系数相同，实际优化强度并不相同，因此该结果不能被描述为纯粹隔离中心化操作的因果效应。完整表与区间见 `SECOND_PRIORITY_REPORT.md` 和 `SEED1_CONTROLS.json`。

## 差异化 reference 教师目标是否会迁移到学生

控制比较为 Fixed、Uniform、Target-specific 三组 reference 教师及对应学生。教师固定目标成员、teacher ID、初始化、输入顺序和 600 updates，只改变 rank 1–9 的 CCC reference；学生固定完整初始 state、8,820 个有序多时间视图、训练顺序、预算、velocity，以及 A0 的中心化残差尺度和系数，只替换教师输出库。三项匹配审计均通过。

- 教师 FRC 顺序为 Uniform `1.537155` > Target-specific `1.050503` > Fixed `0.797126`；学生保持 Uniform `1.574821` > Target-specific `1.101366` > Fixed `0.837835`。
- 教师 FRDiv 顺序为 Fixed `0.202366` > Target-specific `0.190064` > Uniform `0.101901`；学生保持 Fixed `0.190907` > Target-specific `0.178959` > Uniform `0.091454`。
- Target-specific 学生相对 Fixed 的 FRC 为 `+0.263531`，session 95% CI `[+0.176308,+0.320128]`，FRDiv 为 `−0.011948`，区间 `[−0.012806,−0.010667]`。
- Uniform 学生相对 Fixed 的 FRC 为 `+0.736986`，但 FRDiv 为 `−0.099453`；Target-specific 学生相对 Uniform 的 exact FRD 为 `−3.494724`，区间 `[−6.204149,−0.090451]`，FRDiv 为 `+0.087505`。

可写为：reference 规则在教师端形成可控的相关性—多样性取舍，该 FRC/FRDiv 顺序在同配置学生中保持；Target-specific 比 Uniform 保留显著更多多样性，并获得更低的学生 exact FRD。不能写成 Target-specific 全面优于其他 reference，因为 Uniform 的 FRC 最高，且 Target-specific 对 Fixed 的学生 exact FRD 区间跨 0。本组只有一个学生训练 seed；完整原始/后处理表与全部配对区间见 `REFERENCE_CONTROLS_REPORT.md` 和 `REFERENCE_CONTROLS.json`。
